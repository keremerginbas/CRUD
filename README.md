# XRE Partners — Kurumsal Hizmetler Web Sitesi

XRE Partners kurumsal hizmetler kataloğundan (28 sayfa) üretilmiş tek sayfalık React web sitesi.

- Kapak / hero, XRE Partners’a bakış ve 4 hizmet grubu
- 25 hizmetin tamamı: filtre, arama ve detay penceresi (`#hizmet/<ad>` bağlantısıyla paylaşılabilir)
- Çalışma modeli (4 adım) ve iletişim bölümü
- Mobil uyumlu

Tüm içerik `src/data.js` dosyasındadır; metinleri buradan güncelleyebilirsiniz.

## Komutlar

```bash
npm install
npm start       # http://localhost:3000
npm run build   # build/ klasörüne yayına hazır çıktı
```
